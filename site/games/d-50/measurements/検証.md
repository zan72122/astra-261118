# 雨の商店街の状態測定

Nodeで物理・音響モデルを1/120秒以下の刻みで積分し、0.05秒ごとに記録した。無操作10秒、開地歩行10秒、屋根下歩行10秒は各201標本。指のお手本を待つ一周は2,742標本、137.05秒、56.94 m。入口に戻った後、もう一度傘を開いて二周目に入れた。

## 現象別の測定

更新箇所は simulation.js の関数名。音響の周波数と反射時間は Web Audio に渡す値。画面欄には状態が駆動するモデルの部位を記した。

| 状態変数と更新箇所 | 画面・音に出る効果 | 実測値 |
|---|---|---|
| drops[].y・generation ／ weather | 粒ごとに重力で落下。傘・屋根・地面へ接触した粒を終了し、上空から次の粒が落ちる | 無操作10秒に3,366回世代交代。同じ粒の落下は最大0.340 m／0.05秒 |
| cells[].water・wave ／ weather | 36区画の水膜が降雨・隣の区画からの流入・排水で変化し、石畳の映り込みが揺れる | 無操作10秒の水膜厚変化は−0.00008〜＋1.261 mm |
| gutters[].load・y・vy ／ weather | 軒先に蓄えた水が各容量に達すると離れ、落下後に路面を揺らす | 12か所の軒から無操作10秒に46滴が分離 |
| rib[].opening・bend・wet ／ umbrella、weather、press | 10本の傘骨をバネと抵抗で開く。雨粒と指の力が局所をたわませ、隣の区画に伝わって減衰する | 一周の布の変位は−48.37〜＋17.23 mm。比較歩行後の平均水膜は開地0.137 mm、屋根下0.044 mm |
| vx・vz・speed ／ walk | 指の方向に速度がつき、離すと抵抗で止まる。濡れた場所での一歩が波を生む | 巡航中の記録0.607〜1.200 m/s。指を離した瞬間は0.729 m/s |
| pools[].h・rings[].radius ／ walk、weather | 6か所の浅い水たまりに独立した波紋が広がり、振動と音が減衰する | 水面変位の絶対値は最大2.96 mm、波紋の半径は最大0.566 m |
| cutoff・reflection・density ／ weather | 開地で傘布の近い雨音、屋根下でブリキの響き、店内で遠い雨音になる | 開地3,400 Hz・22 ms、屋根下1,100 Hz・104 ms。店内の最小帯域上限506 Hz、雨音密度は開地の5.28% |
| bulbs[].heat・guides[].heat ／ weather、guideLights | 近くの店灯が温まり、次の入口へ続く路面の真鍮灯が順に明るくなる | 店灯の熱状態は基準値の0.503〜1.016倍。路面灯は最大99.95% |
| bootY・soles[] ／ shops | 靴が木・石・浅い水の台に着地し、台が沈んで戻る。接触時だけ材質音が鳴る | 靴の上昇は最大0.356 m、台の沈み込みは最大8.44 mm |
| page[].a・v ／ shops | 背から縁へ15区画の曲げが伝わる。指を離すと残りの紙が追いつき、紙舟が現れる | 先端区画の最大回転181.96° |
| gate・flow・wheelV・boat ／ waterworks | 水門が持ち上がって流量が増し、水車が回って紙舟を運ぶ。舟は水路の端で接岸する | 水門の上昇は最大0.616 m、水車は最大2.246 rad/s、舟の航程4.100 m |
| rain・mist・rainbow ／ weather、waterworks | 広場の雨粒が減り、噴水のしぶきに虹が現れる | 雨量は開地の14.00%まで低下。虹の強度係数は最大96.32% |
| bells[].angle・clapper、springWind・cartZ ／ waterworks | ベルの舌が内壁に当たって音が残る。鍵で巻いたゼンマイが車軸を回し、荷車が入口へ走る | ベルの最大振幅21.20°、蓄えた巻き角4.459 rad、荷車の移動28.670 m |

**隣接する0.05秒間の最大差**　歩行位置0.060 m、布のたわみ18.60 mm、傘骨の開度6.58ポイント、水膜厚0.00720 mm、水たまりの水位0.747 mm、紙の曲げ角14.66°、水門40.68 mm、舟103.82 mm、ベル6.82°、帯域上限64.85 Hz、初期反射2.281 ms。

異なる単位の量は個別に比較した。水膜・路面振動・布の曲げ・傘骨開度・紙・店灯・水たまり・試し履きの台・ベルの各配列で、動いている全区画の増分が一致した記録は0回。全区画が静止した刻みは除いた。雨粒は世代番号を記録し、接触した粒と上空に生じた次の粒を区別した。

## 歩行条件の比較

同じ乱数種で傘を開き、同じ段階・同じ左右の指操作を与えた。開始位置の奥行きだけを1.50 mと−10.36 mに変えた。両条件の歩行距離は7.4463 m。後半5秒に発音した傘布の接触音は開地50回、屋根下0回。ブリキ音はそれぞれ0回、77回。

## 再実行と記録

`node games/d-50/state-test.cjs` で再実行できる。state-0.05s.jsonl.gz は各刻みの記録、summary.json は区画別の範囲と最大差。シミュレーション上の時間で測定した。実機の発音は未試聴。画面全体のHSV彩度中央値、反射・ブルームの見え方、実機フレームレートは描画未確認。
