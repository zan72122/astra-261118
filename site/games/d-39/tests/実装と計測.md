# 雨上がりの通りの状態と計測

ゲームは `../index.html` から起動する。物理更新は `simulation.js` の固定刻み 1/120 秒で進む。`window.__GAME__.step(dt)` の引数は秒、`getState()` は取得時の状態のコピー。長さは 1 ワールド単位が 0.31 m、水面の格子高は m、靴内水位は cm、水路の貯留量は L。

## 何が動きを生み、どこで止まるか

| 部位と更新関数 | 力、区切り、止めた後の動き |
|---|---|
| 各長靴の `x, y, z, vx, vy, vz, fill, mass, slosh` ／ `boots, splash` | 指に追従する復元力と質量から一歩を積分する。底が接地すると落下を止め、水を靴内へ移す。接地後も足首の傾きと靴内水面が減衰する。タイルで排水する。 |
| 3か所の水面の `pools[].h, v` ／ `wake, waves` | 各格子は隣接する4格子との水位差で加速する。靴底、指、落滴が触れた範囲に力を入れる。岸の外では伝播が途切れ、抵抗で波が収まる。反射面の頂点と法線を更新する。 |
| 各飛沫の `drops[].y, vy` ／ `splash, waves` | 踏速の2乗から飛沫の到達高を算出し、粒ごとの初速へ変換する。離水後は重力で落下し、着水すると消えて小波を残す。岸に達した輪はその弧で途切れる。 |
| 葉と紙舟の `vx, vz, spin, roll` ／ `stroke, floats` | 指が押した位置と距離に応じて運動量を伝える。葉は水面の傾きと岸からの押し戻しを受ける。舟は流路に沿って進み、浮力と抵抗で揺れが収まる。 |
| 受け皿の `catchment, cupAngle, cupV`、水路の `water, flux` ／ `current` | 雨の重みで支点まわりのトルクが増す。傾きが注ぎ口の高さを越えると水がこぼれる。空になると皿が戻り、水は上流から隣の区画へ順に渡る。各区画の残留水位で流出が止まる。 |
| 水車の `wheelAngle, wheelSpeed` ／ `current` | 末端の流量と指の力で回る。手を放すと軸の抵抗で減速する。次の周回から、軸のピンが四分の一回転ごとに音板を弾く。 |
| 鎖の `chain[].angle, speed` と浮遊粒子の `motes[].vx, vy, life` ／ `air` | 鎖は隣の輪の張力、自重、風、受け皿からの衝撃で揺れる。粒子は風に流され、雨で下降する。粒子の寿命が尽きると薄れて消え、別の粒が発生する。 |
| 玄関の `dusk, lamp, keys, keySpeed` ／ `story, splash` | 空の明るさに応じて灯りが点灯する。踏んだタイルだけが沈み、接触後はばねと減衰により元へ戻る。 |
| 音の `bottomHz, footCutoff, cutoff` ／ `splash, current, LaneSound.update` | 深さと路面で底音を決め、飛沫には濾波したノイズと短い水滴音を重ねる。靴内水位と軒下の遮蔽量は別々のローパスフィルターに作用する。 |

## 再現と記録

リポジトリのルートで `node games/d-39/tests/state.test.cjs` を実行すると、同じ乱数種から `measurements.json` と `samples.jsonl.gz` を再生成する。記録間隔は 0.05 秒。詳細試験の格子高は 10 µm 単位、格子速度は 100 µm/s 単位の整数で保存し、差分検査には丸める前の値を使う。

無操作、踏速だけを変えた2試行、4場面の往復、靴内水位だけを変えた2試行で、合計1,394状態を記録した。別の180秒の連続操作試験は、長靴の位置と質量、水車の角度、末端流量、灯り、場面と周回を3,601状態記録した。

変化した水面格子群3,147区間、葉・鎖・水路3,068区間について、同じ刻みでの各区画の増分を比較した。全区画が一律に変化した区間は0件。飛沫は同じ粒子IDの生存中を比較し、発生と着水を境界として扱った。

詳細試験の隣接刻み間の最大差は、水位9.47 mm、長靴の位置90.35 mm、靴質量0.0648 kg、葉11.00 mm、紙舟21.19 mm、飛沫111.36 mm、水路1区画0.0398 L、受け皿3.92°、灯り9.36パーセントポイント。

画面内の彩度中央値、反射、影、実機での見え方は描画未確認。音の周波数は合成器に渡す状態値で、実機での聴感は未確認。
