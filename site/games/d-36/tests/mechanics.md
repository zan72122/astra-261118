# ふうりんのえんがわの状態と計測

距離は m、時間は s、角度は rad。simulation.js が直前の状態から 1/120 秒ずつ積分する。画面の縦横比は模型の配置と透視投影に使う。getState() は状態のコピーを返す。

| 現象・更新関数 | 区画と力 | 接触・停止・余韻 |
| --- | --- | --- |
| 局所風 moveAir | 9地点の風速 u。指との距離、吹き出しの強さ、周囲の微風から駆動圧を求める。風速に応じて渦の位相が進む | 入力を離すと最初の風の塊 puff と駆動圧 drive が別の速さで抜ける。風速の上限は 5 m/s |
| 鐘と舌 moveBells | ガラス47 g、鉄145 g、陶器86 g。風圧と短冊から受ける力、重力による復元、減衰を鐘と舌に別々に加える | 舌が内壁に向かって接触すると、相対角速度を反転し鐘に運動量を渡す。離れて再び当たると次の打音になる |
| 紙の短冊 moveBells | 1枚につき8節。風圧、上端の拘束、両隣との曲げ、速度抵抗から各節の変形を積分する | 自由端は力を受けて遅れて曲がる。風を離すと根元と節間の復元力で振れが収まる |
| 打音 audio.js の event・tone | 接触速度を音の立ち上がりへ渡し、材質ごとの固有周波数と部分音を合成する | 発音のたびに独立した減衰包絡を作る。ガラスにはわずかに離れた周波数を重ね、鉄は長く、陶器は短く減衰する |
| 布 moveGarden | 洗濯物3枚とカーテン1枚に各4×5区画。風圧、上と横の張力、湿り wet に応じた復元・抵抗を使う | 上辺に取り付け、裾は自由。風を受けた縁から乾き、乾いた裾が持ち上がって庭が開ける。風が抜けたあとも波が伝わる |
| 葉 moveGarden | 22枚に個別の葉柄の角度・角速度。葉の位置と向きで受風量が変わる | 葉柄が曲がりきる角度で弱く反発する。風を離すと表へ戻り、角速度が減衰する |
| 水と水滴 moveWater | 6×6の水面に水位と速度。隣の水位差、風圧、着水時の速度変化からさざ波が伝わる | 竹筒の先で水滴が育ち、分離して重力で落ちる。着水して消えると別の水滴が生まれる。花びらは水流と局所風で運ばれ、鉢の縁に触れる |
| 光と花火 moveLight | 太陽高度と変化速度。夕方は風の通過量、帰路は朝の日差しに相当する高度へ追従する。花火は個々の火の粉に位置・速度・寿命を持つ | 火の粉は空気抵抗と重力で散って消える。低い遠音を開花より遅らせる |
| 風車 moveToys | 羽根の受けるトルクと軸摩擦から角速度を更新。軸のカムが翼を動かし、巻き取り量 hoist で木の鳥が上がる | 鳥が巻き取りの上端に達すると次の遊びが開く。風が切れた軸は惰性で回り、巻き取りはゆっくりほどける |
| 紙飛行機 moveToys | 折り翼の位置と速度、風に対する姿勢。指から遠ざかると噴流が弱まり、揚力と重力で高度が変わる | 庭奥の戻り風で旋回し、縁側へ滑空する。着地時に速度を落とす。午後の光と最初の構図へ連続して戻る |
| 埃 moveLight | 32粒のそれぞれが、その場所の風速で移流する | 視野外の境界を越えた粒は反対側から流入する。世代を記録し、境界通過を移動量から分離する |

## Node テスト

ゲームフォルダーで `node tests/state.test.cjs` を実行する。描画・音声出力は実行しない。

- 同じ乱数種から無操作10秒、0.65 m/s と4.60 m/s の風をそれぞれ6秒入れて4秒離す試行、3.70 m/s で7段階を一周する試行を記録する。
- state-trace.csv.gz は0.05秒ごとのCSV。列名に単位と区画番号を記載する。火の粉は粒子IDで、水滴は世代で対応づける。
- measurements.json に区画ごとの隣接刻みの最大差、全区画の変化量が一致した刻みの数、三材質の発音イベント数、合成器への周波数指定、着地までの距離・時間を集計する。
- 数値検査には局所風の上限、非対象物の入力拒否、短いタッチでの打音、離した後の減衰、固定刻みの再現性、全段階の到達と復帰を含む。
